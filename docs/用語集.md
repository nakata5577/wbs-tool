# 用語集

業務用語（日本語）と英語識別子の対訳辞書。実装時に新しい業務概念を命名したらこの表に追記する（同一概念に複数の英語名が生まれる「訳語のブレ」を防ぐ。`post_edit.py` がローマ字識別子を検知するため、英語名をここで確定させてから実装する）。

| 業務用語（日本語） | 英語識別子 | 使用箇所・備考 |
|----------------|-----------|------------|
| プロジェクト | Project | DB テーブル名・API パス・コンポーネント名 |
| タスク | Task | DB テーブル名・API パス・コンポーネント名 |
| マイルストーン | Milestone | DB テーブル名・API パス・コンポーネント名 |
| WBS エディタ | WbsEditor | コンポーネント名（`WbsEditor.tsx`）|
| ガントチャート | GanttChart | コンポーネント名（`GanttChart.tsx`）|
| ガントバー | GanttBar | コンポーネント名（`GanttBar.tsx`）|
| 進捗率 | progress | DB カラム・プロパティ名（0〜100 の整数） |
| 担当者 | assignee | DB カラム・プロパティ名（フリーテキスト） |
| ステータス | status | DB カラム・プロパティ名（enum 文字列） |
| 通知 | Notification | DB テーブル名・API パス・コンポーネント名 |
| コメント | Comment | DB テーブル名・API パス・コンポーネント名 |
| 開始日 | startDate / start_date | フロント（camelCase）/ バック・DB（snake_case） |
| 終了日 | endDate / end_date | フロント（camelCase）/ バック・DB（snake_case） |
| 論理削除 | isDeleted / is_deleted | フロント（camelCase）/ バック・DB（snake_case）。`True` = 削除済み |
| 並び順 | sortOrder / sort_order | フロント（camelCase）/ バック・DB（snake_case）。D&D 並び替えに使用 |
| 既読 | isRead / is_read | フロント（camelCase）/ バック・DB（snake_case）。通知の既読フラグ |
| 親タスク | parent / parentId / parent_id | 自己参照による階層構造（NULL = ルートタスク） |
| ルートタスク | rootTask | `parent_id = NULL` のタスク（最上位階層） |
| 達成条件 | achievementCriteria / achievement_criteria | マイルストーンの達成条件テキスト |
