# 操作マニュアル

WBS・マイルストーン管理ツール のエンドユーザー向け操作手順。

> **対象読者**: チームメンバー（エンジニア・PM）
> **前提**: 社内ネットワーク（LAN/VPN）に接続済み
> **動作環境**: Google Chrome / Microsoft Edge（最新版）、1280×720 以上

---

## 1. アクセス方法

ブラウザで以下の URL を開く（URL はデプロイ後に確定）:

```
http://<デプロイ先アドレス>/
```

認証・ログインは不要。

---

## 2. プロジェクト管理

### 2.1 プロジェクトを作成する

1. トップページ（プロジェクト一覧）を開く
2. 「新規プロジェクト」ボタンをクリック
3. プロジェクト名・説明を入力して「作成」をクリック
4. 作成したプロジェクトのカードが一覧に表示される

### 2.2 プロジェクトを開く

プロジェクトカードをクリックするとダッシュボードに移動する。

### 2.3 プロジェクトを編集・削除する

ダッシュボードの「設定」アイコンからプロジェクト名・説明の編集、および削除が可能。

---

## 3. WBS エディタ

### 3.1 タスクを追加する

1. WBS エディタ（「WBS」タブ）を開く
2. 「タスクを追加」ボタンをクリック（または既存タスクの末尾行で Enter）
3. タスク名を入力して確定

### 3.2 タスクを階層化する（親子関係）

- タスクを別タスクの下にドラッグ＆ドロップすると子タスクになる
- 子タスクの左端をドラッグして親タスクの外に移動すると昇格する

### 3.3 タスクに担当者・期日・進捗を設定する

タスク行をクリックするとタスク詳細パネルが開く。以下の属性を設定できる:

| 属性 | 設定方法 |
|------|---------|
| 担当者 | テキスト入力（フリーテキスト） |
| 開始日 / 終了日 | カレンダーピッカーで選択 |
| 進捗率 | スライダーまたは 0〜100 の数値入力 |
| ステータス | ドロップダウン（未着手 / 進行中 / 完了 / 保留） |

### 3.4 タスクを並び替える

タスク行の左端のドラッグハンドルを掴んでドラッグ＆ドロップする。

---

## 4. マイルストーン管理

### 4.1 マイルストーンを追加する

1. ダッシュボードまたは WBS エディタの「マイルストーン」タブを開く
2. 「マイルストーンを追加」をクリック
3. 名前・日付・達成条件を入力して「保存」

### 4.2 マイルストーンを達成済みにする

マイルストーン一覧でステータスを「達成」に変更する。

---

## 5. ガントチャート

### 5.1 ガントチャートを表示する

ダッシュボードの「ガント」タブをクリック。タスクのバーとマイルストーンのダイヤモンドマーカーが表示される。

### 5.2 ビューを切り替える

「週」/「月」ボタンで表示単位を切り替える。

### 5.3 期間をドラッグで変更する

ガントバーをドラッグすると開始日・終了日が変更される。バーの端をドラッグすると期間を伸縮できる。

---

## 6. コメント

### 6.1 コメントを投稿する

1. タスク詳細パネルを開く
2. 「コメント」セクションのテキストエリアにコメントを入力
3. 投稿者名（フリーテキスト）を入力
4. 「投稿」をクリック

### 6.2 コメントを編集・削除する

コメントの右側のメニュー（…）から「編集」または「削除」を選択する。

---

## 7. 通知センター

### 7.1 通知を確認する

ヘッダーのベルアイコン（未読数が表示される）をクリックすると通知センターが開く。

### 7.2 既読にする

通知項目をクリックするとタスク詳細に移動し、その通知が既読になる。「すべて既読」ボタンで一括既読も可能。

---

## FAQ

**Q: 担当者を選択するドロップダウンがない**
A: このツールは認証・ユーザー管理機能がないため、担当者名はフリーテキストで入力します。

**Q: データが消えた**
A: 削除操作は論理削除のため、管理者（開発チーム）が復旧できる場合があります。開発チームに連絡してください。

**Q: ガントチャートが遅い**
A: 100 タスク以上のプロジェクトでは描画に 2 秒程度かかることがあります。ブラウザのリロードをお試しください。
